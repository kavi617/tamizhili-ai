# தமிழி AI – Project Overview

## 🏆 Project Title

தமிழி AI – Interactive Tamil History Learning System

---

## 🎯 Project Goal

தமிழி AI is an intelligent system designed to teach Tamil history in an engaging and interactive way. Instead of static information, it transforms historical facts into stories, characters, and conversations using artificial intelligence.

The goal is to make learning Tamil history immersive, fun, and easy to understand for students and users.

---

## 💡 Problem Statement

Traditional learning methods for history are often:

* Text-heavy and boring
* Not interactive
* Difficult to visualize

There is no system that combines Tamil history with modern AI to create an engaging learning experience.

---

## 🚀 Solution

தமிழி AI solves this by using:

* AI-powered chat interface
* Multi-agent system
* Vector database (ChromaDB)
* Retrieval-Augmented Generation (RAG)

It allows users to:

* Ask questions about Tamil history
* Interact with historical figures
* Explore events through storytelling

---

## 🧠 System Architecture

The system uses a multi-agent architecture:

1. Root Agent – Controls the system and manages flow
2. Input Classifier – Understands user query
3. Historian Agent – Retrieves accurate historical data
4. Character & Story Agent – Creates interactive storytelling
5. Validation Agent – Ensures accuracy

---

## ⚙️ Technologies Used

Frontend:

* Next.js
* Tailwind CSS

Backend:

* FastAPI (Python)

AI & Data:

* OpenAI API (LLM)
* ChromaDB (Vector Database)
* RAG (Retrieval-Augmented Generation)

---

## 🔄 How It Works

1. User enters a question
2. Query is processed by the Root Agent
3. Relevant data is retrieved from ChromaDB
4. Multiple agents generate responses
5. Final answer is validated and returned
